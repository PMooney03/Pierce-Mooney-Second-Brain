# Demo corpus (safe for GitHub)

Synthetic sample notes so CharlesGPT still answers questions when `Year1`–`Year4` are missing.

**Not real coursework.** Invented for demos only.

Point ingest at this folder:

```powershell
# backend/.env
DOCUMENTS_PATH=demo_corpus
```

Then run ingest. Your private `Year*` folders stay local and gitignored.
